- Демо-админ-панель для изменения цен.

## Важное ограничение

Сейчас `admin.html` сохраняет изменения только в `localStorage`, то есть только в текущем браузере.

Чтобы изменение цены отображалось у всех посетителей, нужно:

1. Создать проект на https://supabase.com
2. Выполнить SQL из файла `supabase-schema.sql`.
3. Подключить Supabase к `app.js` и `admin.js`.
4. Настроить Supabase Auth.
5. Создать отдельную роль администратора.
6. Добавить безопасные RLS-политики для изменения товаров.
7. Загрузить файлы в GitHub-репозиторий.
8. Включить GitHub Pages.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий, например `tut-dessert`.
2. Загрузите в корень репозитория:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `admin.html`
   - `admin.js`
   - `supabase-schema.sql`
   - `README.md`
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
5. Нажмите Save.
6. GitHub выдаст адрес опубликованного сайта.
