Фото загружается сразу в Supabase Storage. Максимальный размер одного файла — 8 МБ. Поддерживаются JPG, PNG, WEBP и AVIF.

Для товаров с одной ценой заполняй поле «Цена». Для нескольких размеров можно оставить поле «Цена» пустым и написать, например, «2800 / 4000» в поле «Цена / размеры».
